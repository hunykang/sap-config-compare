2026-10-07 — Table(CDS View) 페이지 추가

FI·CO·SD·MM·PP 주요 테이블 31건 · Cloud dev / Key User app 표시

주요 테이블에 대응하는 S/4HANA CDS 뷰와 개발 활용 가능 여부(Use in Cloud Development / Use in Key User Apps)를 모듈별로 정리한 페이지를 열었습니다. FI는 기본으로 펼쳐지고, 확인되지 않은 항목은 확인중 태그로 표시됩니다.

2026-10-07 — Auto-posting 페이지 추가

MM-FI 자동계정결정(OBYC) 40종 · 배포 완료

MM-FI 자동전표 트랜잭션 키 40종의 설명과 회계분개(차/대)를 정리한 Auto-posting 페이지를 열었습니다. 검색·카테고리 필터와 분개 복사 버튼을 지원합니다.

2026-10-05 — 용어집 페이지 추가

용어 95개 · 비교표와 양방향 링크

SAP FI 용어 95개를 S/4HANA 기준으로 쉽게 정리한 용어집 페이지를 열었습니다. 용어 → 비교표 설정 항목, 설정 항목 → 용어로 서로 오갈 수 있습니다.

2026-10-05 — 사이트 오픈

비교표 117개 항목 · 지식그래프 공개

ECC / PCE / Public 3-way 비교 가이드 사이트를 열었습니다. Public "확인 중" 항목은 추후 보완할 예정입니다.
