Public 기준 이벤트 기반 프로세스 2건을 지도에 추가했습니다. 이벤트 기반 재공계산(CO 레인, 생산 단계)은 출고·작업확정 때마다 재공이 잡히고 최종 입고 때 소멸·차이 정산되는 흐름이고, 이벤트 기반 수익인식(O2C 레인, 판매 단계)은 출고·청구 사건마다 수익을 인식하는 흐름입니다. 외부 연계 리스절에는 Public 임차 스콥 아이템(1T6·21P·34N)과 임대 스콥 아이템(21Q·전대 2SB·2SA·34O·2O9, 서비스 계약 21R)을 넣었습니다.

2026-10-24 — 외부 연계 13절 확장 · CBO개발 내용 표기 · 펌뱅킹·CMS 정리

프로세스 52노드 · 외부 연계 13절

외부 연계가 6절에서 13절로 늘었습니다. 분개엔진, SCM 연계(물류 · 구매 · 생산 · 주문 · 정산), 리스회계, 펌뱅킹·CMS, 내부회계관리, 관리회계 수익성분석, 자산관리 솔루션이 새로 들어갔고, 지도 노드에도 외부 연계 행으로 녹였습니다. CBO개발 배지가 있던 노드에는 코드 대신 어떤 업무를 개발했는지(마스터 대량 생성, 대금지급 확정, 전자세금계산서 확정전송, 자동 수금반제, 법인카드·유형별 경비전표, 홈텍스 신고파일, 자산 마스터 대량생성)를 적었고, 근거가 없는 건설중자산 정산·감가상각 노드의 배지는 뺐습니다. 펌뱅킹·CMS 절은 연결회계 바로 위로 옮기고, 세부 기능(입출금, 집금, 가상계좌, 전자어음, B2B, 환율)을 나열했습니다.
