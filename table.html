Table · CDS View 매핑

FI·CO·SD·MM·PP·PS 주요 테이블에 대응하는 S/4HANA CDS 뷰와, 개발(Key User App / Cloud Development)에서 가져다 쓸 수 있는지를 정리한 표입니다. 모듈별로 쭉 펼쳐져 있고, 주제 칩을 누르면 해당 모듈만 볼 수 있습니다. CDS 뷰 이름은 외부 검색으로 연결됩니다.

✓ 사용 가능(릴리스됨) – 사용 불가 확인중 아직 검증되지 않음 혼합 뷰마다 다름(기타 칸 참고)

참고 · 출처

  • 내부 T-Code 매핑 정리 자료 — P주요필드 탭의 I_BUSINESSPARTNER 필드 상세를 반영했습니다. 자료에 없는 CDS뷰는 공개 자료로 대조했고, 그래도 확인할 수 없는 항목은 확인중 태그를 달았습니다.
  • I_ARLINEITEM의 Cloud Development / Key User App 값은 TDD 시스템의 ADT API State 화면(스크린샷)에서 확인한 값입니다.
  • S/4HANA Public에서는 DB 테이블을 직접 조회할 수 없고, 릴리스된 CDS 뷰로만 데이터에 접근할 수 있습니다.
  • 확인중 채우는 방법: ADT에서 CDS 뷰 우클릭 → Properties → API State 탭에서 Use in Cloud Development / Use in Key User Apps 확인, 또는 Fiori View Browser 앱 → Released Views에서 조회. 릴리스 상태는 버전에 따라 바뀔 수 있습니다.
  • 잘못된 매핑이나 새로 확인된 릴리스 상태는 피드백으로 알려주세요.
